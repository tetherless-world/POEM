Digital Administration Resources

Please find information and resources below for administering the RCADS digitally.

RCADS questionnaires are given an official label that follows this format: RCADS - [Instrument Length] - [Respondent] - [Language Code] - [Country Code] - [Version Number].

  • Instrument Length: Either 47-items or 25-items, shortened to 47 or 25, respectively.
  • Respondent: Either Youth or Caregiver, abbreviated to Y or CG, respectively.
  • Language: We use the internationally standardized ISO 639 language codes, which you can find here: https://en.wikipedia.org/wiki/List_of_ISO_639_language_codes
  • Country: We use the internationally standardized ISO 3166 country codes, which you can find here: https://en.wikipedia.org/wiki/ISO_3166-1
  • Version Number: This is assigned by the RCADS team when it has been established that more than one version exists. We aim to assign version numbers in the chronological order they were created.

Some versions of the RCADS may not be available within the below resources. As our team receives and converts RCADS versions into an interoperable data format, the below drop-down lists will be updated. 

FHIR

An Electronic Health Record (EHR) is a digital version of a patient’s medical history, maintained by healthcare providers.

Fast Healthcare Interoperability Resources (FHIR) is a standard that defines how healthcare data should be structured and exchanged among different systems. To be able to administer a digital version of the RCADS in an EHR system that is compliant with FHIR, it must be stored in a FHIR-compliant data and file format. The data format depends on the file format, which includes JSON, XML, RDF, and TTL.

You can find more information about FHIR here: https://www.hl7.org/fhir/overview.html

Below, you will find a JSON file generator for every supported version of the RCADS. If you would like to download a PDF file, please go to the PDF page under the Downloads tab.

Non-FHIR

For non-FHIR-compliant EHR systems, we provide Excel files that contain all components of the RCADS that appear on the PDF version. Unlike the JSON files above, the Excel files do not contain response option values for scoring the RCADS. For this information, please see our Manual Scoring Page.
